## Reglas del proyecto

Antes de trabajar, lee todos los archivos de `.rules/` y consulta las skills del proyecto para identificar las aplicables a la tarea. Aplica únicamente las skills relevantes.

Las instrucciones del usuario determinan el alcance y prevalecen sobre las convenciones del proyecto y las skills. Para código nuevo, sigue `.rules/rules-codigo.md`. No cambies el enfoque del código existente por iniciativa propia.

Respeta la fase actual: una demo puede tener páginas o funcionalidades pendientes deliberadamente. En auditorías, distingue los pendientes de fases futuras de los errores de la entrega actual.

## Development

When starting the dev server, use background mode:

```
astro dev --background
```

Manage the background server with `astro dev stop`, `astro dev status`, and `astro dev logs`.
